# ANIMORA

A static one-page/mini-site style anime fandom project built with HTML, CSS, and JavaScript.

## Pages
- index.html
- dr-stone.html
- slam-dunk.html
- yowamushi-pedal.html
- demon-slayer.html
- fate-zero.html
- contact.html — introduces the five group members and describes the project

## Folders
- css/style.css — site styling
- js/script.js — mobile navigation, active navigation, and scroll reveal
- assets/ — original SVG placeholders for media

## Notes
The media graphics are original placeholders. Replace them with screenshots or fan work that you are permitted to use if your assignment requires actual anime images.


## Artwork note
The bundled JPG artwork in this revision is cropped from the cinematic visual mockup used for the redesign. The site structure is ready for replacement with official promotional/key art. For official reference galleries, see the Dr. STONE character/gallery pages, Yowamushi Pedal official site, Demon Slayer character portal, and Fate/Zero official cast site.


## Contact page
Update the five sample names and each member role in `contact.html` to match your group. For the assignment requirement about visible individual contributions, each member should also complete their assigned task and commit their own changes under their GitHub account.
